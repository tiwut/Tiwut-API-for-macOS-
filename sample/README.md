# Tiwut API Samples

This directory provides interactive and automated sample implementations demonstrating the Tiwut API across web, CFeel, C++, and shell environments.

---

## Directory Contents

- **`web/`**: Real-time macOS System Control Center Web UI built with `tiwut-web-sdk-static` and icons from `Icon-Library`.
- **`cfeel/`**: 5 standalone native `.cfeel` programs compiling directly to ARM64 assembly with `cfeelc`.
- **`cpp/`**: C++17 client application integrated with `CPP-Headers` (`tiwut_hpp_time.hpp`, `tiwut_hpp_random.hpp`, `tiwut_hpp_file.hpp`).
- **`bash/`**:
  - `50_usecases.sh`: Automated test suite executing all 50 use case endpoints.
  - `quickstart.sh`: Single-command build, run, test, and teardown runner.
- **`bin/`**: Compiled output binaries generated by `make samples`.

---

## Running Samples

### 1. Build All Samples
```bash
make samples
```

### 2. Run CFeel Executables
```bash
./sample/bin/cfeel_monitor
./sample/bin/cfeel_process
./sample/bin/cfeel_power
./sample/bin/cfeel_notifier
./sample/bin/cfeel_bench
```

### 3. Run C++ Executable
```bash
./sample/bin/cpp_sample
```

### 4. Run Automated 50 Use Cases Test Suite
```bash
bash sample/bash/50_usecases.sh
```
