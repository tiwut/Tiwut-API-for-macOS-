# Components

Modular UI elements designed to consume the Tiwut SDK Theme Variables.

## Sub-Libraries
Each component resides in its own folder and functions as an independent sub-library.
- `buttons/`: Interactive button styles with SVG icon support.
- `cards/`: Glassmorphic and solid card layouts.
- `inputs/`: Form controls and text inputs.
- `navigation/`: Navbars, sidebars, and menus.

## Usage
You can drop any component folder directly into another project. Just ensure the core theme variables are available.
