# Cards

Reusable card layouts including glassmorphism.

## Usage
Include the CSS:
```html
<link rel="stylesheet" href="path/to/components/cards/card.css">
```

Example HTML:
```html
<div class="t-card t-card-glass">
  <div class="t-card-header">
    <h3 class="t-card-title">Card Title</h3>
  </div>
  <div class="t-card-body">
    <p>This is the content of the card.</p>
  </div>
  <div class="t-card-footer">
    <button class="t-btn t-btn-primary">Action</button>
  </div>
</div>
```
