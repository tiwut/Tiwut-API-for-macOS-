# Buttons

Reusable button component.

## Usage
Include the CSS:
```html
<link rel="stylesheet" href="path/to/components/buttons/button.css">
```

Add classes to your button elements:
```html
<button class="t-btn t-btn-primary">
  <img src="../../icons/darkmode/ui/check.svg" class="t-btn-icon" alt="check icon" />
  Primary Action
</button>

<button class="t-btn t-btn-glass">Glass Button</button>
<button class="t-btn t-btn-outline">Outline</button>
```
